# IPv4 Addressing and Network Connectivity Lab

## Overview

This project demonstrates practical IPv4 addressing and network connectivity testing in a virtualized cybersecurity lab built with Oracle VirtualBox.

The lab uses Ubuntu Server and Windows Server 2022 to explore network interface configuration, subnet masks, default gateways, DNS resolution, and connectivity troubleshooting.

## Lab Environment

- **Virtualization:** Oracle VirtualBox
- **Operating systems:** Ubuntu Server and Windows Server 2022
- **Networking modes:** NAT, Internal Network, and Host-Only
- **Internal Network:** `10.10.20.0/24`
- **Host-Only Network:** `192.168.220.0/24`

## Skills Demonstrated

- IPv4 address identification and configuration
- Subnet masks and `/24` networks
- Default gateway identification
- DNS resolution and connectivity testing
- Linux network diagnostic commands
- Windows network diagnostic commands
- Virtual machine network segmentation
- ICMP-based connectivity testing
- Basic firewall troubleshooting

## Purpose

The purpose of this project is to develop foundational networking skills that support further learning in cybersecurity, system administration, and Security Operations Center (SOC) environments.

*This repository documents a hands-on learning lab. Results reflect the configuration and tests performed in the virtual environment.*
